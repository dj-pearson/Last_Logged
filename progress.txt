## Codebase Patterns
- Xcode project uses MVVM folder structure: Models/, ViewModels/, Views/{Home,Detail,Onboarding,Settings,Components}/, Services/, Widget/, Utilities/
- SPM dependencies declared in project.pbxproj via XCRemoteSwiftPackageReference (supabase-swift, purchases-ios, TelemetryDeck SwiftClient)
- App Group identifier: group.com.pearsonmedia.lastlogged (configured in LastLogged.entitlements)
- Bundle identifier: com.pearsonmedia.lastlogged
- iOS 17+ deployment target, SwiftUI lifecycle
- Empty directories use .gitkeep files for git tracking
- SwiftData models: TrackerItem, CompletionLog, TrackerCategory in Models/ folder
- SyncStatus enum (synced/pending/conflict) in Models/SyncStatus.swift — used by TrackerItem
- ModelContainer configured with App Group shared store in LastLoggedApp.swift (URL: appGroupURL/LastLogged.sqlite)
- TrackerItem links to TrackerCategory via categoryId (UUID), not a SwiftData @Relationship
- CompletionLog links to TrackerItem via trackerItemId (UUID), not a SwiftData @Relationship
- DataSeeder in Utilities/ handles first-launch seed data; called from LastLoggedApp .onAppear
- Use FetchDescriptor + fetchCount for lightweight existence checks in SwiftData
- ViewModels are @Observable classes that take ModelContext in init; views pass modelContext from SwiftUI environment
- Color(hex:) extension on Color lives in Views/Home/HomeView.swift — converts "#RRGGBB" hex strings to SwiftUI Color
- ContentView is a thin wrapper that renders HomeView; new top-level navigation goes through HomeView
- Highest pbxproj IDs: A1...0025 (BuildFile), A2...0021 (FileRef)
- TrackerRowView takes `onLog: () -> Void` closure — must be provided when constructing the row
- `import UIKit` needed for haptic feedback (UIImpactFeedbackGenerator) — SwiftUI alone doesn't expose it
- AddTrackerView takes HomeViewModel (not ModelContext) and uses its createItem method; present as .sheet from HomeView
- AddTrackerView supports edit mode via optional `editingItem: TrackerItem?` parameter — pre-populates all fields from existing item
- TrackerDetailViewModel is @Observable, takes ModelContext + TrackerItem — prep for US-024 (completion history)
- Use `.sheet(item:)` with TrackerItem for edit sheet — @Model classes conform to Identifiable via PersistentModel
- Swipe actions use `.swipeActions(edge: .trailing, allowsFullSwipe: false)` for non-destructive-by-default archive
- Context menu on rows: `.contextMenu` with Edit and Archive options
- CategoryTemplates keyed by category name string — match templates to categories via `category.name`
- HomeView toolbar + button is a Menu with "New Tracker" and "Add from Templates" — add new creation options there
- NotificationService.shared is the singleton for local notifications — call `rescheduleAllNotifications(modelContext:)` after any tracker mutation
- Notification uses `UNCalendarNotificationTrigger` at 9 AM on due dates; 64-item limit handled by overdue priority sort
- Widget extension target: LastLoggedWidgetExtension (com.pearsonmedia.lastlogged.widget), shares models via duplicate PBXBuildFile entries
- WidgetDataProvider.shared in LastLogged/Widget/ — creates its own ModelContainer from App Group URL; compiled in both targets
- OverdueItem struct + UrgencyLevel enum live in WidgetDataProvider.swift — use for widget display data
- Widget extension files are in LastLoggedWidget/ directory (sibling to LastLogged/)
- Use `@Environment(\.widgetFamily)` to switch widget layouts by size; `containerBackground(.fill.tertiary, for: .widget)` for iOS 17+ backgrounds
- OverdueItem.sampleItems provides placeholder/preview data for widget gallery — use `context.isPreview` in getSnapshot
- Interactive widget buttons use `Button(intent:)` with AppIntents (iOS 17+); only medium/large widgets support per-item buttons, small uses `widgetURL`
- `Color(hex:)` extension is duplicated in widget target (LastLoggedWidget.swift) since HomeView.swift isn't compiled there
- LogCompletionIntent in LastLoggedWidget/ — uses WidgetDataProvider's shared container to read/write SwiftData and reloads timelines after logging
- RevenueCatService.shared is the singleton for subscriptions — @Observable so views react to tier changes; call configure() in LastLoggedApp.init()
- Entitlement name "premium" shared by monthly, annual, and lifetime products — distinguish lifetime by checking productIdentifier == "lifetime"
