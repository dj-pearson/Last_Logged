# Ralph Progress Log
Started: 2026-03-24

## Codebase Patterns
- Xcode project uses MVVM folder structure: Models/, ViewModels/, Views/{Home,Detail,Onboarding,Settings,Components}/, Services/, Widget/, Utilities/
- SPM dependencies declared in project.pbxproj via XCRemoteSwiftPackageReference (supabase-swift, purchases-ios, TelemetryDeck SwiftClient)
- App Group identifier: group.com.pearsonmedia.lastlogged (configured in LastLogged.entitlements)
- Bundle identifier: com.pearsonmedia.lastlogged
- iOS 17+ deployment target, SwiftUI lifecycle
- Empty directories use .gitkeep files for git tracking
- SwiftData models: TrackerItem, CompletionLog, TrackerCategory in Models/ folder
- SyncStatus enum (synced/pending/conflict) in Models/SyncStatus.swift — used by TrackerItem
- ModelContainer configured with App Group shared store in LastLoggedApp.swift (URL: appGroupURL/LastLogged.sqlite)
- TrackerItem links to TrackerCategory via categoryId (UUID), not a SwiftData @Relationship
- CompletionLog links to TrackerItem via trackerItemId (UUID), not a SwiftData @Relationship
- DataSeeder in Utilities/ handles first-launch seed data; called from LastLoggedApp .onAppear
- Use FetchDescriptor + fetchCount for lightweight existence checks in SwiftData
- ViewModels are @Observable classes that take ModelContext in init; views pass modelContext from SwiftUI environment
- Color(hex:) extension on Color lives in Views/Home/HomeView.swift — converts "#RRGGBB" hex strings to SwiftUI Color
- ContentView is a thin wrapper that renders HomeView; new top-level navigation goes through HomeView
- Highest pbxproj IDs: A1...000D (BuildFile), A2...000D (FileRef)
- TrackerRowView takes `onLog: () -> Void` closure — must be provided when constructing the row
- `import UIKit` needed for haptic feedback (UIImpactFeedbackGenerator) — SwiftUI alone doesn't expose it
